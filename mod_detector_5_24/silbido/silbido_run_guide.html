Running Silbido in MATLAB

One script runs the Silbido whistle detector on 12 public dolphin and whale recordings from the DCLDE 2011 dataset, then makes a zip file to send back.

What you need

  • The file run_silbido_dclde2011.m, sent with this guide
  • Desktop MATLAB, R2019b or newer
  • Signal Processing Toolbox and Image Processing Toolbox
  • Internet and about 1.5 GB of free disk space

Steps

  1. Give Java more memory. Open Preferences (called Settings in the newest MATLAB versions), go to General › Java Heap Memory, set it to 2048 MB, then restart MATLAB.

  2. Set up a folder. Create a new empty folder, put run_silbido_dclde2011.m in it, and make that folder MATLAB's current folder.

  3. Start the script. Type this in the Command Window and press Enter:

    run_silbido_dclde2011

    It downloads Silbido 3.0 and the recordings (about 1.1 GB) from NOAA's public data bucket, then processes the recordings one at a time. Progress appears in the Command Window.

  4. Wait for it to finish. The time depends on the computer and may be an hour or more. If it stops or MATLAB closes, run the same command from the same folder. It keeps finished downloads and recordings.

  5. Send the result. When it prints DONE, send back silbido_detections.zip from that folder. You can delete the rest of the folder after that.

If something goes wrong

MessageWhat to do
Silbido needs the ... ToolboxInstall that toolbox with the MATLAB Add-On Explorer, then run the script again.
at least 1 GB of Java heap memoryDo step 1, restart MATLAB, then run the script again.
could not download ...Check the internet connection and run the script again later. Some university networks block downloads, so another network may help.
Anything elseSend a screenshot or copy of the red error text. This is the script's first real run, so it may need a small fix.

Optional: if you have the Deep Learning Toolbox and its ONNX converter support package, run_silbido_dclde2011(true) also runs Silbido's deep-learning version. Please try the normal command first. The script has not been tried on MATLAB Online, so use desktop MATLAB.
