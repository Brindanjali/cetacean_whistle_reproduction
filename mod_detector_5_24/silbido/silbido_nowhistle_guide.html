Running Silbido: step-by-step instructions

Thank you for lending your MATLAB! This page explains everything; you do not need to know anything about the project. Your part takes about 20 minutes of your time; the computer then works on its own for roughly 1 hour.

What this is, in short

We are writing a research paper about a computer program that finds dolphin whistles in underwater sound recordings. We compare it with Silbido, the standard whistle detector, which only runs in MATLAB. One script runs Silbido on 146 one-minute recordings of beaked whales and sperm whales (from a public NOAA survey) and packs the results into a small zip file, which you send back. Everything stays in one folder that you can delete afterwards.

Before you start (5 minutes)

  • Desktop MATLAB, version R2019b or newer (not MATLAB Online). To check, type version in the MATLAB Command Window and press Enter; the release in the answer (for example R2023a) must be R2019b or later.
  • Two toolboxes: Signal Processing Toolbox and Image Processing Toolbox. To check, type ver and press Enter, then look for both names in the list. If one is missing, it can be added under Home › Add-Ons if your licence includes it; if not, please stop and tell the person who sent you this.
  • About 6 GB of free disk space and a working internet connection.
  • Keep the computer awake: plug in the charger and stop it from going to sleep for about 1–2 hours.
  • The Google Drive link to the folder silbido_nowhistle_v1, from the person who asked you.

Steps

  1. Give MATLAB’s Java more memory

    Silbido needs this. In MATLAB, open Home › Preferences (in MATLAB R2025a and newer: Home › Settings), choose MATLAB › General › Java Heap Memory, move the slider to 2048 MB, click OK, then close and reopen MATLAB. If it is already 2048 MB or more, there is nothing to do. (You can set it back afterwards; see the end of this page.)

  2. Create an empty folder

    Create a new folder called silbido_run on your Desktop. Everything for this run goes in there.

    Windows: right-click the Desktop › New › Folder. Its path is then C:\Users\YOUR-NAME\Desktop\silbido_run

    Mac: right-click the Desktop › New Folder. Its path is then /Users/YOUR-NAME/Desktop/silbido_run

  3. Download the script

    Open the Google Drive link. You will see two files and one folder:

    • run_silbido_nowhistle.m (the script)
    • silbido_nowhistle_guide.html (this page)
    • nowhistle_wav (the recordings)

    Right-click run_silbido_nowhistle.m › Download. When it has downloaded, move it from your Downloads folder into silbido_run.

  4. Download the recordings (about 3.4 GB)

    Right-click the folder nowhistle_wav › Download. Google Drive first shows “Preparing download” or “Zipping” for a few minutes, then downloads one, two or three zip files. If the browser asks whether to allow several downloads, click Allow. This takes about 5–30 minutes, depending on the internet speed.

    Wait until all zip files have finished downloading, then move them all into silbido_run.

  5. Unzip the recordings

    Windows: right-click each zip file › Extract All… › make sure the destination is your silbido_run folder › Extract.

    Mac: double-click each zip file; it unzips next to itself.

    It is fine if this makes several folders (for example nowhistle_wav and nowhistle_wav 2): the script searches every folder inside silbido_run. Inside them there should be many files named like 1705_20170827_210035_544.wav and one file nowhistle_wav_manifest.csv. Afterwards you can delete the zip files.

  6. Point MATLAB at the folder

    In MATLAB’s Command Window, type cd and the folder path in quotes and brackets, then press Enter. Replace YOUR-NAME with your user name:

    Windows:

    cd('C:\Users\YOUR-NAME\Desktop\silbido_run')

    Mac:

    cd('/Users/YOUR-NAME/Desktop/silbido_run')

    (Or use the folder bar at the top of MATLAB to go to silbido_run.) To check, type this and press Enter; the answer must include run_silbido_nowhistle.m:

    ls

  7. Start the run

    Type this and press Enter:

    run_silbido_nowhistle

    Now leave it running. You can use the computer for other things, but do not close MATLAB and do not let the computer sleep.

  8. What you will see (all normal)

    Messages appear in the Command Window roughly in this order (numbers will differ):

    checking the size and MD5 of 146 WAV files (about a minute)...
all 146 WAV files present and correct
downloaded ...silbido-3.0.zip
run silbido-graph on nowhistle (146 files): ...
  [1/146] 1705_20170827_210035_544.wav: 12 tonals in 3 s
  [2/146] ...
MAIN RUN DONE. ...silbido_nowhistle_detections.zip is ready (it is updated again at the end).
downloaded ...  (12 more recordings, about 1.1 GB in all)
run silbido-graph on dclde2011 (12 files): ...
run silbido-graph-thr8 ...   run silbido-graph-thr12 ...
DONE. Send this file back: ...silbido_nowhistle_detections.zip

    Between these lines Silbido prints its own lines such as Detected 12 tonals, rejected ... and small timing tables; that is normal.

    Please wait for the final DONE, not only MAIN RUN DONE: the later part saves us from having to ask you again.

  9. Send the result back

    In silbido_run there is now a file silbido_nowhistle_detections.zip (a few MB). Send it to the person who asked you, by email or Google Drive. That is all!

If it stops in the middle

If MATLAB closes, the computer sleeps or the internet drops: open MATLAB and do step 6 (the same folder) and step 7 (the same command) again. Finished work is kept, and it continues where it stopped.

If you see a red error

The red text saysWhat to do
Undefined function or variable 'run_silbido_nowhistle' or Unrecognized functionMATLAB is not in the right folder, or the script is not in it. Check steps 3 and 6, then try again.
nowhistle_wav_manifest.csv not foundThe recordings are not in silbido_run yet, or not unzipped. Do steps 4 and 5, then run again.
... WAV files are missing or damagedA zip file is missing or a download broke off. Download the nowhistle_wav folder again, unzip all parts into silbido_run, then run again.
Silbido needs the ... ToolboxThat toolbox is missing (see “Before you start”). Install it if your licence allows, or tell the person who asked you.
at least 1 GB of Java heap memory or Java heap spaceDo step 1, close and reopen MATLAB, then steps 6 and 7 again.
could not download ...Check the internet connection and run again later. Some university or company networks block downloads; another network (for example home Wi-Fi) may help.
Anything elseTake a screenshot of the red text and send it to the person who asked you. The script has not been run before, so it may need a small fix.

What this does to your computer

  • It only creates and changes files inside the silbido_run folder. Nothing is installed.
  • It downloads Silbido 3.0 (30 MB) and 12 public test recordings (1.1 GB) from NOAA’s public data storage (storage.googleapis.com/noaa-passive-bioacoustic) and checks each download.
  • It adds Silbido to MATLAB’s search path for the current session only; that is gone when MATLAB closes.
  • It sends nothing anywhere by itself: you send the zip yourself. All recordings are public scientific data.

Cleaning up afterwards

  • Once the zip has been received, delete the whole silbido_run folder (about 5 GB) and the zip files in your Downloads folder.
  • If you changed the Java memory in step 1 and want it back, set the slider to its old value and restart MATLAB.

If time is short: run_silbido_nowhistle(false) does only the main run (about 15–30 minutes), but the full run is preferred.
